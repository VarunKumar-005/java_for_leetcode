## 🧭 How to use this repository (Best Strategy)

### 1) Pick a branch by topic 📚
Each branch is organized to help focused learning.

Examples:
- `arrays`
- `strings`
- `linked-list`
- `trees`
- `graphs`
- `dynamic-programming`
- `interview-revision`

### 2) Study in this order 🪜
1. Read concept notes  
2. Understand core patterns  
3. Solve easy → medium → hard  
4. Revisit mistakes and edge cases  
5. Revise weekly

### 3) Practice like interview mode 🎤
- Set timer ⏱️
- Explain your approach out loud
- Write clean code
- Analyze time + space complexity
